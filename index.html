DYNAMIC MAP LEGEND

SPATIAL METHODOLOGY

1. The administrative boundary JSON is retrieved directly from GitHub.

2. Region, LGA, district, ward and enumeration area filters identify the selected boundary features.

3. The map is zoomed to the selected geography.

4. Sentinel-2 imagery is requested using the selected raster function.

5. A polygon mask visually hides the imagery outside the selected boundary.

6. Boundary area statistics are calculated from the selected polygon geometries.

DATA LIMITATIONS

The ImageServer layer provides rendered satellite imagery. This dashboard does not calculate pixel-level mean, minimum, maximum, standard deviation, index-class area or zonal statistics. The index chart shows reference interpretation ranges, not measured results for the selected AOI.

Sentinel-2 has no thermal bands. Land Surface Temperature requires a thermal satellite product such as MODIS or Landsat.
